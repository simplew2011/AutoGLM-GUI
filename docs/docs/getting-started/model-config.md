---
title: 模型配置（界面版）
---

模型配置在「对话」页面完成，所有字段与按钮与界面保持一致。

## 配置入口

- 按钮：**「配置」**
- 保存按钮：**「保存配置」**
- 取消按钮：**「取消」**

## 必填字段（基础模型）

- **「Base URL」**
- **「API Key」**
- **「模型名称」**

## 分层代理相关字段

当你使用分层代理时，需要填写决策模型字段：

- **「决策模型 Base URL」**
- **「决策模型 API Key」**
- **「决策模型名称」**

界面上还会出现以下标签：

- 「视觉模型」
- 「决策模型」
- 「选择预设配置」
- 「选择决策模型预设」

## 对话模式相关字段

当你使用对话模式时，需要配置对话模型：

- **「对话模型 Base URL」**（可选，默认继承基础模型配置）
- **「对话模型 API Key」**（可选，默认继承基础模型配置）
- **「对话模型名称」**（可选，默认继承基础模型配置）
- **「启用思考模式」**（可选，显示模型推理过程）

> **提示**：对话模型配置独立于 GUI Agent 模型，可以使用不同的模型服务。如果不单独配置，将继承基础模型的配置。
